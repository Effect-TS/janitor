# Triage labels

Use these strings in each issue's `Status:` line.

| Canonical role    | Tracker status    | Meaning                                           |
| ----------------- | ----------------- | ------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue            |
| `needs-info`      | `needs-info`      | Waiting on the reporter for more information      |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an unattended agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation                     |
| `wontfix`         | `wontfix`         | Will not be implemented                           |

When a skill names a triage role, use its tracker status from this table.

Wayfinding tickets use the lifecycle statuses defined in `docs/agents/issue-tracker.md`.
