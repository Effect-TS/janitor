docs/settings-mockups

Settings screen, six layouts

Each page covers the same states: GitHub connected, never linked or disconnected; Slack connected, never linked, disconnected or not configured; and team management as an admin or as a member. Use the control bar at the top of each page to switch states and between day and night shift, or the deep links below.

Data shown is what the account view returns today: issuer, subject, email, role, status, timestamps, and per-platform links with workspace ID, account ID, display name, status, linked and ended times. No avatars, no token expiry, no invitations exist in the model, so none are shown.
